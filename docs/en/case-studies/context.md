# Integration case: Context knowledge workflows

[简体中文](../../zh-CN/case-studies/context.md)

[Context](https://github.com/context4ai/context) uses Agent Graph as the work-contract layer behind one public Agent entry. Context owns the workspace facts and side effects; Agent Graph evaluates those facts and returns the next legal Route, required resources, Gate, and completion contract.

The canonical case study now lives beside the Context workflow so its explanation and replay can evolve with the product integration:

- [Read the complete case study](https://github.com/context4ai/context/blob/main/docs/en/case-studies/agent-graph-workflow.md)
- [Watch the interactive replay](https://context4ai.github.io/context/case-studies/workflow/?lang=en)
- [Inspect the published workflow](https://github.com/context4ai/context/tree/main/packages/context-cli/context-workflow)

Agent Graph keeps this short integration entry for discovery and compatibility; Context is the source of truth for the case content, replay data, and integration-specific tests.
