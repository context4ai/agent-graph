# 集成案例：Context 知识工作流

[English](../../en/case-studies/context.md)

[Context](https://github.com/context4ai/context) 在一个公开 Agent 入口背后使用 Agent Graph 作为工作契约层。Context 负责工作区事实和实际副作用，Agent Graph 根据事实返回下一条合法 Route、所需资源、Gate 与完成契约。

案例正文现在与 Context 工作流放在同一仓库，说明和回放可以随产品接入一起演进：

- [阅读完整案例](https://github.com/context4ai/context/blob/main/docs/zh-CN/case-studies/agent-graph-workflow.md)
- [观看交互式回放](https://context4ai.github.io/context/case-studies/workflow/?lang=zh)
- [检查公开工作流](https://github.com/context4ai/context/tree/main/packages/context-cli/context-workflow)

Agent Graph 保留这份精简入口，用于能力发现和历史链接兼容；案例内容、回放数据和接入专属测试以 Context 为唯一真源。
